# Общий лейаут платформы

`PlatformLayout` задаёт три рабочие области. Левый слот принимает навигацию, центральный — содержимое продукта, правый — необязательную панель. Заголовок и действия находятся над рабочей областью. Истории показывают границы слотов и их состояния на демонстрационных заглушках.

## Подключение

```tsx
import { PlatformLayout } from './PlatformLayout';

export function ProductPage() {
  return (
    <PlatformLayout
      title="Рабочая область"
      navigation={{ expanded: <p>Навигация</p> }}
      rightPanel={{ title: 'Фильтры', content: <p>Содержимое панели</p> }}
    >
      <p>Содержимое продукта</p>
    </PlatformLayout>
  );
}
```

| Свойство | Назначение |
| --- | --- |
| `title`, `actions` | Заголовок страницы и слот действий |
| `navigation.expanded`, `navigation.compact` | Содержимое широкой и компактной левой области |
| `navigation.label` | Доступная подпись левой области |
| `children` | Произвольное содержимое центральной области |
| `rightPanel` | Заголовок и содержимое панели. `triggerLabel` задаёт подпись кнопки, если она отличается от заголовка |
| `defaultNavigationCollapsed`, `defaultRightPanelOpen` | Начальные состояния. По умолчанию слева 228 px, справа панель закрыта |
| `className`, `dataTestId` | Класс и тестовый идентификатор корневого контейнера |

На 1440 px и шире используется один режим. Левая область переключается между 228 и 62 px. Открытая правая колонка резервирует 300 px, закрытие возвращает это место центру. Заголовок остаётся сверху. Левая область, центр и содержимое правой панели прокручиваются независимо. Широкий контент прокручивается внутри центра. Встроенные кнопки поддерживают Tab, Enter и Space. Escape внутри правой панели закрывает её и возвращает фокус на кнопку открытия.

В монорепозитории перенесите `src/PlatformLayout` и истории из `src/demo` в подходящую библиотеку. Истории используют публичный импорт `@frontend/ui-kit`. Компонент ожидает тему и шрифты UI Kit от приложения. Все встроенные кнопки используют `NativeButton`, который передаёт `aria-expanded` и `aria-controls`. Контейнер действий использует `Flex`. Слоты, CSS Grid и панель встроены в сам лейаут.

## Локальный Storybook

Для отдельной сборки используйте Node.js 22 или новее. Распакуйте предоставленный архив так, чтобы появился путь `local-ui-kit/ui-kit/src`. Архив и извлечённые файлы хранятся локально. Настройки в `dev/` подключают оригинальные компоненты, токены и шрифты из архива.

```bash
unzip /path/to/ui-kit.zip -d local-ui-kit
npm ci
npm run typecheck
npm run lint
npm run storybook
npm run build:storybook
```

Storybook запускается на порту 6006. Статическая сборка появляется в `storybook-static/`. `storybook-static/layout-preview.html` открывает интерактивный каркас без интерфейса Storybook. Для отдельной HTML-страницы используйте `npm run build:preview` и откройте `preview-static/index.html`.

Собранное превью содержит код компонентов и шрифты UI Kit. Для публикации используйте разрешённое закрытое окружение.
